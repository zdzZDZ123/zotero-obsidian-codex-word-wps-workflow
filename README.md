# Zotero × Obsidian × Codex Research Workflow

[简体中文](README.zh-CN.md)

An open, reproducible research workflow that connects:

- **Zotero** as the source-of-truth literature library and PDF evidence layer;
- **Obsidian** as the durable personal knowledge base and project-control layer;
- **Codex** as the research agent for retrieval, synthesis, drafting, review, and traceable handoffs.

This repository publishes the workflow, configuration contracts, prompts, templates, and local Codex/Obsidian skills. It deliberately excludes personal libraries, PDFs, credentials, OAuth state, MCP bearer tokens, and third-party plugin binaries.

## What is reproducible

- A ready-to-copy Obsidian vault skeleton with templates and five local workflow skills.
- A pinned component matrix for Obsidian, Zotero, and their plugins.
- Sanitized Obsidian plugin settings; each computer installs plugins from their official sources.
- Agent prompts that install and configure Obsidian, Zotero, and Codex without a bundled installer.
- A traceability contract: every important claim must remain linked to a real source, full-text status, and page-level evidence where available.
- Local audit scripts and CI checks for configuration integrity and accidental secret leakage.

## Quick start

1. Clone this repository.
2. Give [`prompts/01-setup-obsidian.md`](prompts/01-setup-obsidian.md) to Codex on the target computer.
3. Give [`prompts/02-setup-zotero.md`](prompts/02-setup-zotero.md) to Codex.
4. After both applications work independently, run [`prompts/03-connect-codex.md`](prompts/03-connect-codex.md).
5. Prove the integration with [`prompts/04-run-first-research.md`](prompts/04-run-first-research.md).

The workflow is complete only when Codex can read a real Zotero PDF passage with a page reference, write a traceable Obsidian note, and create/read back a test Zotero child note.

## Repository map

```text
obsidian/vault-template/   Reusable vault structure, settings, templates, and skills
zotero/                    Zotero installation and configuration contract
codex/                     Codex integration and operating contract
prompts/                   End-to-end deployment prompts for another computer
docs/                      Architecture, component matrix, security, troubleshooting

```

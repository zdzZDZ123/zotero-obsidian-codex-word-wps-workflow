# KnowledgeBase

把资料变成可复用的知识，再把知识变成实际产出。

## 快速入口

- [[00-Inbox/_Inbox|收件箱]]：先收集，后整理
- [[05-Daily/_Daily|每日记录]]：当天的想法与工作痕迹
- [[10-Projects/_Projects|项目]]：有明确完成标准的工作
- [[20-Areas/_Areas|领域]]：需要长期维护的责任
- [[30-Resources/_Resources|资源地图]]：按主题组织参考资料
- [[40-Knowledge/_Knowledge|常青知识]]：可以反复复用的观点与方法
- [[50-Outputs/_Outputs|成果]]：文章、方案、报告、复盘
- [[90-System/Operating Manual|使用手册]]
- [[90-System/Knowledge Dashboard|知识库仪表盘]]
- [[10-Projects/Knowledge Base Board|项目看板]]
- [[90-System/Review Queue|待复盘问题]]
- [[90-System/Evolution Log|进化记录]]

## 今天怎么用

1. `使用 $capture-source 收录这份资料。`
2. `使用 $distill-knowledge 整理这篇收件箱笔记。`
3. `使用 $start-project 把这个目标变成可执行项目。`
4. `使用 $weekly-review 完成本周复盘并改进知识库。`
5. `使用 $run-traceable-research 把 Zotero 证据推进为可追溯的研究与论文交付。`

> [!tip] 最小习惯
> 任何内容先进入收件箱；任何项目都写下“下一步”；每周让 Codex 做一次复盘。

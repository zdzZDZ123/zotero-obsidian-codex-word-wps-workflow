# Start Project

1. Read `AGENTS.md`, `10-Projects/_Projects.md`, and search the vault for up to seven highly relevant notes.
2. Clarify the outcome from available context. Ask only if a missing decision would materially change the project.
3. Create `10-Projects/<clear outcome name>.md` using `99-Templates/Project.md`.
4. Define observable done criteria, constraints, and one physical next action that can be started without further planning.
5. Link only relevant knowledge, source, area, and output notes. Do not create placeholder notes.
6. Record important assumptions under Decisions.
7. Add the project under Active in `10-Projects/_Projects.md`.

When work completes, change the project to `status: done`, link the deliverable in `50-Outputs`, and capture reusable lessons in `40-Knowledge`.

# Distill Knowledge

1. Read `AGENTS.md`, the selected source note, `40-Knowledge/_Knowledge.md`, and search the vault for genuinely related notes.
2. Identify only ideas that remain useful beyond the source. Skip trivia and avoid duplicating an existing concept.
3. Create or update one note per durable idea in `40-Knowledge/`, using `99-Templates/Evergreen.md` as the schema.
4. Write in the user's own words. Explain why the idea holds, when it helps, and how it relates to existing notes.
5. Link every derived note back to its source with an Obsidian wiki link; keep the external URL in the original source note.
6. Add created notes to `40-Knowledge/_Knowledge.md`.
7. Update the source note to `status: processed` and list every result under `distilled_to`.
8. Update `00-Inbox/_Inbox.md` so its state remains accurate.

Do not force an output. If the source adds nothing durable, record that conclusion in the source note and explain why.

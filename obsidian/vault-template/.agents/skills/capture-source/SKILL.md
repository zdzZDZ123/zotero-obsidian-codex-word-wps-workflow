# Capture Source

1. Read `AGENTS.md` and preserve the source exactly enough to trace it later.
2. Create `00-Inbox/YYYY-MM-DD <short descriptive title>.md` using `99-Templates/Capture.md` as the schema.
3. Fill only known metadata. Use an empty value for unknown author or source details; never guess.
4. Write a one-sentence summary, key content, why it may matter, and unresolved questions. Keep quoted excerpts short and clearly marked.
5. Add 1-5 useful topic values. Do not build a new taxonomy merely for one item.
6. Add the note to `00-Inbox/_Inbox.md` under current items.
7. Leave `status: inbox`. If the source is unavailable, set `status: needs-source`, record what is missing, and do not invent a summary.

Finish by reporting the created note and the single best next action, usually `$distill-knowledge`.

# Prompt 04 — Run the first traceable research task

Copy the prompt below into Codex after the integration test passes.

---

Use `$academic-research-suite` together with the Vault-local `$run-traceable-research` skill to complete a small, evidence-traceable research task from my Zotero library.

Choose a bounded question that matches the available library evidence. Before drafting, inventory relevant Zotero items and mark metadata-only versus full-text-accessible sources. Create or update an Obsidian project note with the research question, inclusion logic, done criteria, next action, evidence table, and output path.

For each material claim, preserve the Zotero item identity and page/location when the PDF supports it. Separate direct source statements from your inference. If evidence is unavailable or conflicting, say so; never invent a citation, quotation, page, DOI, method, sample size, or result.

Produce:

1. an Obsidian source note for each included paper;
2. atomic evergreen notes for reusable findings;
3. a synthesis matrix of claim → source → page/full-text status → confidence;
4. a concise research memo with limitations and unresolved questions;
5. a project-status update and next action.

Write back to Zotero only when the note is useful at the source level and clearly label agent-generated content. Finish by auditing every claim in the memo against the evidence matrix and reporting any unverified statement.
